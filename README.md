# NCDC IT Problem Dashboard | Power BI

## 📊 Project Overview

The **NCDC IT Problem Dashboard** is a Power BI project developed as part of my **3rd internship assignment at SWYNEX Technologies**.

The main objective of this project is to visualize and analyze IT support tickets. The dashboard provides useful information about ticket status, issue types, ticket creation trends, and the distribution of tickets across different divisions.

It helps users understand IT support activities and monitor the status of reported problems through interactive visualizations.

## 🎯 Project Objectives

- Monitor the total number of IT support tickets.
- Track open and closed tickets.
- Analyze the ticket closure rate.
- Understand ticket creation trends over time.
- Identify the most frequently reported IT issues.
- Compare ticket counts across different divisions.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Data Visualization** – Charts, KPI cards, and interactive filters
- **Data Analysis** – Ticket status, issue types, and division-wise analysis

## 📈 Dashboard Features

### 1. KPI Cards
Displays key performance indicators:
- Total Tickets: 147
- Closed Tickets: 146
- Open Tickets: 1
- Closure Rate: 99.32%

### 2. Ticket by Created Date
A line chart that shows ticket creation trends over time and helps identify changes in the number of reported issues.

### 3. Ticket Status
A doughnut chart that displays the distribution of open and closed tickets.

### 4. Ticket by Issue Type
Visualizes different categories of IT issues, including:
- Printer
- Network/Internet
- Desktop
- Software
- Other

### 5. Tickets by Division
A bar chart that compares the number of tickets reported by different divisions.

### 6. Interactive Issue Type Filter
Allows users to filter the dashboard by issue type and explore the relevant ticket information.
